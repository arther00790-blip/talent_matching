# #10 トップ・静的ページ・仕上げ・公開

## 概要
これまでの部品を組み合わせてトップページを完成させ、静的ページ（About / FAQ / 規約 / プライバシー / 404）を作る。
最後にレスポンシブ・アクセシビリティ・メタ情報を仕上げ、README を書いて GitHub Pages で公開する。

- 対象要件：C-01 / C-03 / C-04 / C-06 / C-07 / 3.2 / 3.5 / 5.4 / 7章（フェーズ9〜11）/ README
- 依存：#01〜#09

## 作成・編集するファイル
| ファイル | 内容 |
|---|---|
| `js/pages/top.js` / `css/pages/top.css` / `index.html` | トップページ |
| `js/components/tabs.js` | 利用ステップのタブ切替（`role="tablist"`） |
| `about.html` / `faq.html` / `terms.html` / `privacy.html` / `404.html` | 静的ページ（`static.css` レイアウト） |

| `tests/links.test.mjs` | 全HTMLの内部リンク切れチェック |
