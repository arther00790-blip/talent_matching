# #09 お問い合わせフォーム（入力・確認・完了）

## 概要
入力 → 確認 → 完了の3ステップの問い合わせフォームを作る。
画面間の受け渡しは `sessionStorage`、外部への送信は行わない。

- 対象要件：C-02 / 2.5 / 3.5 / 5.2（入力内容を外部へ送信しない）
- 依存：#02, #03, #04（`validation.js` / `storage.js`）

## 作成・編集するファイル
| ファイル | 内容 |
|---|---|
| `js/pages/contact.js` | 入力画面：リアルタイム検証、確認画面へ遷移 |
| `js/pages/contact-confirm.js` | 確認画面：内容表示、戻る／送信する |
| `js/pages/contact-complete.js` | 完了画面：一時データ削除 |
| `js/components/step-indicator.js` | 「入力 → 確認 → 完了」ステップ表示 |
| `css/pages/contact.css` | ページ固有スタイル（トークンのみ使用） |
| `contact.html` / `contact-confirm.html` / `contact-complete.html` | `<main>` 内のマークアップ（`form.css` レイアウト） |
| `tests/contact.test.mjs` | フロー制御のテスト |

**編集しないファイル**：共通ベース（`page-base.html` 骨格・`reset.css`・`variables.css`・`base.css`）

## 実装タスク
- [ ] 入力項目
  | 項目 | 必須 | ルール |
  |---|---|---|
  | お名前 | ○ | |
  | メールアドレス | ○ | `type="email"`＋形式チェック |
  | 会社名 | — | |
  | 種別 | ○ | タレント登録について／案件掲載について／取材・提携／その他 |
  | 本文 | ○ | 10〜1000文字（`minlength` / `maxlength`）、文字数カウンター |
  | プライバシーポリシー同意 | ○ | `privacy.html` へのリンク |
- [ ] HTMLの `required` 等を基本に、JSで入力中（`blur` / `input`）にエラー表示。エラーは `aria-describedby` で欄と紐付け
- [ ] 送信時に最初のエラー欄へフォーカス
- [ ] 確認画面へ進むとき `saveContactDraft`、確認画面から「戻る」で入力値を復元
- [ ] 確認画面は `textContent` で表示（`innerHTML` に入力値を入れない）
- [ ] 下書きが無い状態で確認・完了画面を直接開いたら `contact.html` へ戻す
- [ ] 「送信する」→ サーバー送信はせず完了画面へ遷移、完了画面で `clearContactDraft`
- [ ] 二重送信防止（ボタン無効化）

## テスト（先に書く）

- [ ] 下書きなしで確認画面を開くとリダイレクト判定になる
- [ ] 完了後に下書きが削除される
