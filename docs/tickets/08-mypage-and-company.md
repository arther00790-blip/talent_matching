# #08 マイページ・スカウト・案件掲載・おすすめ・デモリセット

## 概要
ロールごとに中身が変わるマイページと、企業側の機能（スカウト送信・案件掲載・応募者管理）、
タレント向けのおすすめ案件、通知バッジ、デモデータのリセットを実装する。
応募型・スカウト型の2つのマッチング導線（6.2）が一通り体験できる状態にする。

- 対象要件：T-06 / T-07 / B-01 / B-03 / B-04 / M-02 / 6.2 / 6.3 / 6.6 / 4.5（リセット）
- 依存：#05, #06, #07

## 作成・編集するファイル
| ファイル | 内容 |
|---|---|
| `js/pages/mypage.js` | ロール判定と各セクションの描画 |
| `js/components/mypage-talent.js` | タレント用：応募履歴・届いたスカウト・おすすめ案件・動画未登録の案内 |
| `js/components/mypage-company.js` | 企業用：応募者一覧・送信したスカウト・掲載中の案件 |
| `js/components/scout-dialog.js` | スカウト送信ダイアログ（`talent.html` から利用） |
| `js/pages/job-new.js` | 案件掲載フォーム |
| `js/lib/status.js` | ステータス遷移の定義と「次へ進める」処理（純粋関数） |
| `css/pages/mypage.css` / `css/pages/job-new.css` | ページ固有スタイル（トークンのみ使用） |
| `mypage.html` / `job-new.html` | `<main>` 内のマークアップ |
| `js/components/header.js` | 通知バッジの追加のみ（#03 で作成済み） |
| `tests/status.test.mjs` / `tests/recommend.test.mjs` | テスト |

**編集しないファイル**：共通ベース（`page-base.html` 骨格・`reset.css`・`variables.css`・`base.css`）
