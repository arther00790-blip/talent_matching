# #06 案件一覧・検索・詳細・応募

## 概要
案件一覧（検索・並び替え）、案件詳細、応募ダイアログ、お気に入りを実装する。
応募データはブラウザ内（localStorage）に保存し、マイページ（#08）で参照できるようにする。

- 対象要件：T-03 / T-04 / T-05 / T-08 / 6.5 / 6.6
- 依存：#02, #03, #04

## 作成・編集するファイル
| ファイル | 内容 |
|---|---|
| `js/pages/jobs.js` | 一覧ページの初期化、フィルター⇔URL同期、並び替え |
| `js/pages/job.js` | 詳細ページ、応募・お気に入り |
| `js/components/job-filter.js` | 案件用フィルターフォーム |
| `js/components/apply-dialog.js` | 応募ダイアログ（#02 の `modal.js` を利用） |
| `css/pages/jobs.css` / `css/pages/job.css` | ページ固有スタイル（トークンのみ使用） |
| `jobs.html` / `job.html` | `<main>` 内のマークアップ |
| `tests/job-page.test.mjs` | 応募データ生成・重複応募防止のテスト |

**編集しないファイル**：共通ベース（`page-base.html` 骨格・`reset.css`・`variables.css`・`base.css`）

## 実装タスク

### 一覧（`jobs.html`）
- [ ] フィルター：職種・ジャンル・地域・報酬下限
- [ ] 並び替え：締切が近い順／新着順／マッチ度順（マッチ度順はタレントロール時のみ有効。`matching.js` を使用）
- [ ] 架空データ＋デモで追加した案件（`stagelink:jobs:added`）を合わせて表示
- [ ] タレントロール時、カードに相性バッジ（◎／○）を表示
- [ ] 締切切れ・`closed` の案件は「募集終了」をテキストで表示
- [ ] スケルトン・空状態・URL同期は #05 と同じ方針

### 詳細（`job.html?id=j001`）
- [ ] 募集要項・条件・スケジュール・報酬・企業名
- [ ] 「この案件に向いている人」欄
- [ ] `videoPreferred` なら「自己紹介動画ありを歓迎」を表示
- [ ] 応募ボタン：タレントロールのみ有効。ゲスト・企業には理由を添えて無効化（例「タレントに切り替えると応募できます」）
- [ ] 応募ダイアログ：一言メッセージ（文字数上限は定数化）→ 送信で `addApplication`、トースト「応募しました！いい知らせが届きますように」
- [ ] 同じ案件への重複応募は「応募済み」表示にしてボタンを無効化
- [ ] お気に入りボタン（`aria-pressed`）、`toggleFavorite` で保存

## テスト（先に書く）
- [ ] 応募データが `Application` 型どおり（`status: "applied"`、`createdAt` がISO文字列）
- [ ] 同じ `jobId` で2回応募できない
- [ ] 並び替え3種の順序が正しい
- [ ] お気に入りのトグルで追加・削除される

## 完了条件
- [ ] 応募するとトーストが出て、マイページ（#08 実装後）に反映される（フェーズ4の完了条件）
- [ ] ダイアログをキーボードで操作でき、閉じるとフォーカスが応募ボタンに戻る
- [ ] 375px / 1440px で崩れない、コンソールエラーなし
