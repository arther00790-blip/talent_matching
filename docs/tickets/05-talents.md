# #05 タレント一覧・検索・詳細（動画表示を含む）

## 概要
タレント一覧（検索・絞り込み）とタレント詳細（写真・自己紹介動画・実績）を実装する。
企業ロールでのタレント検索（B-02）も同じ画面で扱う。

- 対象要件：T-01 / T-02 / T-10 / B-02 / 6.5 / 6.6 / 6.7「表示」
- 依存：#02, #03, #04

## 作成・編集するファイル
| ファイル | 内容 |
|---|---|
| `js/pages/talents.js` | 一覧ページの初期化、フィルター⇔URL同期、描画 |
| `js/pages/talent.js` | 詳細ページの初期化 |
| `js/components/talent-filter.js` | タレント用フィルターフォーム |
| `js/components/video-player.js` | 自己紹介動画プレーヤー（`<video>` 生成） |
| `css/pages/talents.css` / `css/pages/talent.css` | ページ固有スタイル（トークンのみ使用） |
| `talents.html` / `talent.html` | `<main>` 内のマークアップ |
| `tests/talent-page.test.mjs` | URL⇔フィルター変換、動画ソース選択のテスト |

**編集しないファイル**：共通ベース（`page-base.html` 骨格・`reset.css`・`variables.css`・`base.css`）

## 実装タスク

### 一覧（`talents.html`）
- [ ] フィルター：職種・性別・年齢帯・地域・スキルタグ（複数）・キーワード・**動画ありのみ**
- [ ] 絞り込み状態をクエリに反映（`?role=actor&area=東京都`）、URLを開くと状態が復元される
- [ ] 描画前に `renderSkeleton`、0件なら `renderEmptyState`（「条件をゆるめて探す」ボタンでフィルター解除）
- [ ] 件数表示（`aria-live="polite"`）
- [ ] モバイルではフィルターをボトムシートで開閉（`list.css` レイアウト）

### 詳細（`talent.html?id=t001`）
- [ ] IDが無い・存在しない場合は「タレントが見つかりませんでした」＋一覧へ戻るボタン
- [ ] 写真ギャラリーの**上に**動画プレーヤー：`controls` / `preload="metadata"` / `playsinline` / `poster` あり / 自動再生なし / `<track>` を差し込める構造
- [ ] 動画ソースの優先順位：デモ用タレント本人はIndexedDBの動画（#07 の `video-store.js`）→ `introVideo.src`。#07 完了前は `introVideo.src` のみで動作すること
- [ ] 基本情報・スキル（チップ）・出演実績（時系列）・SNSリンク（`rel="noopener"`）
- [ ] 企業ロール時のみ「スカウトする」ボタンの枠を表示（送信処理は #08）
- [ ] 写真には `alt`、ユーザー入力由来の文字列は `textContent` で表示

## テスト（先に書く）
- [ ] フィルター状態 → クエリ文字列 → フィルター状態 の往復で一致する
- [ ] 動画ソース選択：IndexedDBあり→Blob URL、なし→`introVideo.src`、どちらも無し→プレーヤーを出さない
- [ ] 存在しないIDでエラー表示用の状態が返る

## 完了条件
- [ ] 絞り込みがURLに反映され、リロード・URL共有で状態が再現される（フェーズ3の完了条件）
- [ ] 詳細で動画が再生でき、自動再生されない
- [ ] 一覧・トップ用カードで動画ありに「▶ 動画あり」バッジが出る
- [ ] 375px / 1440px で崩れない、コンソールエラーなし
